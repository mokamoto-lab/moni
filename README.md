# ボムデュエル

1台のキーボードで遊ぶ、2人用のローカルボム対戦プロトタイプです。通信やアカウントはありません。

## 起動

リポジトリのルートで静的サーバを立て、ブラウザで開きます。

```bash
python3 -m http.server
```

http://localhost:8000 を開いてください。ビルドは不要です。

## 操作

| プレイヤー | 移動 | 爆弾 |
| --- | --- | --- |
| 1（青・左） | `W` `A` `S` `D` | `Space` |
| 2（赤・右） | 矢印キー | 右 `Shift` |

勝負が終わったら「もう一度あそぶ」か `R` キーで最初からやり直せます。

## ルール

- ステージは 13×11。外周と柱は壊せません。
- 左上と右下からスタートします。
- 最初は爆弾 1 個、火力 2 マス（十字）、スピードは普通です。
- 立っているマスに爆弾を置けます。1マスに爆弾は1個まで。導火線は約 2.5 秒です。
- 置いた直後はその爆弾の上を歩けます。マスを離れると、誰にとっても通れなくなります。
- 爆風は壁と柱で止まります。置いた本人にも当たります。
- 生き残ったほうが勝ちです。同じ爆風で同時に倒れると引き分けです。

## アイテム

試合中、空いているマスに約 8 秒おきにアイテムが出ます。場に同時にあるのは最大 3 個です。踏むとすぐに効きます。

| アイテム | 効果 |
| --- | --- |
| 火力アップ | 爆風の届く距離 +1（最大 8） |
| スピードアップ | 移動が速くなる（上限あり） |
| スピードダウン | 移動が遅くなる（止まれない下限あり） |
| 爆弾追加 | 同時に置ける爆弾 +1（最大 5）。爆発すると枠が戻る |
